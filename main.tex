\section{Formulate the optimal control problem}

\subsection{Problem statement}

Find the minimum time trajectory for a Dubins vehicle starting at some point and heading that goes to a point on a stationary circle and ends up on the boundary of a polytope.


\subsection{Initial conditions}

The vehicle starts at a position $(x_0,y_0) \in \mathbb{R}^2$, with a heading $\theta_0 \in (\!-\!\pi,\pi]$ and a constant speed $v_0$.

We have a circular region $\mathcal{C}$ of radius $r_c$
\begin{align}
    &\mathcal{C} = \{ (x,y) \in \mathbb{R}^2 | (x-x_c)^2 + (y-y_c)^2 = r_c^2 \},\\
    &r_c \in \mathbb{R}^+, \nonumber\\
    &(x_c,y_c) \in  \mathbb{R}^2. \nonumber
\end{align}
% \begin{align}
%     &\mathcal{C} = \{ (x,y,x_c,y_c) \in \mathbb{R}^4, r_c \in \mathbb{R}^+ | (x-x_c)^2 + (y-y_c)^2 = r_c^2\}
% \end{align}

% IMAN SAID TO START WITH A CIRCLE FOR SIMPLICITY FOR THE TARGET HOME POLYTOPE
We also have a terminal area $\mathcal{X}$ that does not overlap with $\mathcal{C}$ and can be of any shape. For the sake of this example, it will be defined as a circle of radius $r_x$, noted as
\begin{align}
    &\mathcal{X} = \{ (x,y) \in \mathbb{R}^2 | (x-x_x)^2 + (y-y_x)^2 = r_x^2 \},\\
    &r_x \in \mathbb{R}^+, \nonumber\\
    &(x_x,y_x) \in  \mathbb{R}^2, \nonumber\\
    &\mathcal{C}\cap \mathcal{X} = \emptyset. \nonumber
\end{align}

        v_0\cos\theta\\v_0\sin\theta\\u
    \end{bmatrix}\\
    &v_0\in \mathbb{R}^+,\\
    &\theta \in (\!-\!\pi,\pi],\\
    &u \in \left[-\frac{v_0}{\rho},\frac{v_0}{\rho}\right],
\end{align}

\subsection{Cost function}

The cost function is
\begin{align}
    J = \underset{u(t)}{\min}\int_{t_0}^{t_f} 1dt
\end{align}
where $t_0$ is the initial time, and $t_f$ is the time at which the vehicle arrived at $(x_f,y_f)$.

Although the objective is to find the fastest path, since the vehicle travels at a constant speed and is assumed to be in a homogeneous environment (friction and drag are constant, and no external perturbations), finding the fastest path is equivalent to finding the shortest path.
% $\square$

\subsection{Boundary conditions}

At the point $(x_g,y_g)$, which is crossed at time $t_g\in (t_0,t_f)$ to make sure the vehicle either touches the boundary of $\mathcal{C}$ or goes fully through it (whichever gives the shortest path), the following state equality needs to be satisfied
\begin{align}
    S_\mathcal{C}(\mathbf{x},t) = (x-x_c)^2 + (y-y_c)^2 - r_c^2 = 0.
\end{align}

At the final destination, the following state equality needs to be satisfied
\begin{align}
    S_\mathcal{X}(\mathbf{x},t) = (x-x_x)^2 + (y-y_x)^2 - r_x^2 = 0
\end{align}
to make sure the vehicle ends up on the boundary of the terminal area $\mathcal{X}$.

\subsection{What needs to be determined}

The intersection points $(x_g,y_g)$ and $(x_f,y_f)$ need to be determined so that they respect the equality constraints and minimize the Hamiltonian. The heading angles at these locations, respectively $\theta_g$ and $\theta_f$, also need to be determined.



\subsection{Hamiltonian and costates}

Create the Hamiltonian for the stated problem
\begin{align}
    H(\mathbf{x},\mathbf{p},u) = 1 + p_xv_0\cos\theta + p_yv_0\sin\theta + p_\theta u
\end{align}
\begin{align}
    \mathbf{\dot{p}} = \begin{bmatrix}
        \dot{p}_x\\\dot{p}_y\\\dot{p}_\theta
    \end{bmatrix}
    = -\pdv{H}{\mathbf{x}}
    = \begin{bmatrix}
        0\\0\\-p_xv_0\sin\theta + p_yv_0\cos\theta
    \end{bmatrix}
    = \begin{bmatrix}
        0\\0\\-p_x \dot{y}(t) + p_y\dot{x}(t)
    \end{bmatrix}
\end{align}
where $p_x$, $p_y$ and $p_\theta$ are the costates of the system.

Since the derivatives of $p_x$ and $p_y$ are equal to zero, it means they are constant and do not depend on time. This will, however, not be the case for $p_\theta$. By integrating $\dot{p_\theta}$, we obtain
\begin{align}
    p_\theta(t) = \int \dot{p}_\theta(t)dt
    = \int (-p_x \dot{y}(t) + p_y\dot{x}(t))dt
    = -p_x y(t) + p_yx(t) + c_1
    \label{eq_ptheta}
\end{align}
where $c_1$ is a constant of integration.

According to the minimum principle, the optimal control $u^*$ will be
\begin{align}
    u^* = \underset{ u \in \left[-\frac{v_0}{\rho},\frac{v_0}{\rho}\right] }{\arg\min} \; H(\mathbf{x},\mathbf{p},u).
\end{align}

Since the only term in $H$ that implicates the use of $u$ is $p_\theta u$, the value of $u$ that minimizes $H$ will depend on the value of $p_\theta$. We can conclude that we will have
\begin{align}
    u^* = \begin{cases}
        -v_0/\rho & p_\theta(t) > 0\\
        v_0/\rho & p_\theta(t) < 0.
    \end{cases}
\end{align}

The case $p_\theta=0$ is not as trivial as the other cases. To obtain the value of $u^*$, we start from equation \ref{eq_ptheta} and isolate $y(t)$
\begin{align}
    p_\theta(t) &= -p_x y(t) + p_yx(t) + c_1 = 0\\
    y(t) &= \frac{p_x}{p_y}x(t) + \frac{c_1}{p_y}.
\end{align}
This is the equation of a straight line. For the vehicle to travel this way, its angular velocity must be equal to 0, which means $u=0$. This means that we will have
\begin{align}
    u^* = \begin{cases}
        -v_0/\rho & p_\theta(t) > 0\\
        0 & p_\theta(t) = 0\\
        v_0/\rho & p_\theta(t) < 0.
    \end{cases}
\end{align}

The next step is to find what is the value of $p_\theta(t)$.
