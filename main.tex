\section{Pose the optimal control problem}

\subsubsection*{Problem statement}

Find the minimum time trajectory for a Dubins vehicle starting at some point and heading that goes to a point on a stationary circle and ends up on the boundary of a polytope.


\subsubsection*{Initial conditions}

The vehicle starts at a position $(x_0,y_0) \in \mathbb{R}^2$, with a heading $\theta_0 \in \;]\!-\!\pi,\pi]$ and a constant speed $v_0$.

We have a circular region $\mathcal{C}$ of radius $r_c$ (notation similar to \cite{Jha20})
\begin{align}
    &\mathcal{C} = \{ (x,y) \in \mathbb{R}^2 | (x-x_c)^2 + (y-y_c)^2 = r_c^2 \},\\
    &r_c \in \mathbb{R}^+, \nonumber\\
    &(x_c,y_c) \in  \mathbb{R}^2. \nonumber
\end{align}
% \begin{align}
%     &\mathcal{C} = \{ (x,y,x_c,y_c) \in \mathbb{R}^4, r_c \in \mathbb{R}^+ | (x-x_c)^2 + (y-y_c)^2 = r_c^2\}
% \end{align}

% IMAN SAID TO START WITH A CIRCLE FOR SIMPLICITY FOR THE TARGET HOME POLYTOPE
We also have a terminal area $\mathcal{X}$ that does not overlap with $\mathcal{C}$ and can be of any shape. For the sake of this example, it will be defined as a circle of radius $r_x$, noted as
\begin{align}
    &\mathcal{X} = \{ (x,y) \in \mathbb{R}^2 | (x-x_x)^2 + (y-y_x)^2 = r_x^2 \},\\
    &r_x \in \mathbb{R}^+, \nonumber\\
    &(x_x,y_x) \in  \mathbb{R}^2, \nonumber\\
    &\mathcal{C}\cap \mathcal{X} = \emptyset. \nonumber
\end{align}


\subsubsection*{Kinematics}

The kinematics of the Dubins vehicle are
\begin{align}
    &\dot{x} = v_0\cos\theta,\\
    &\dot{y} = v_0\sin\theta,\\
    &\dot{\theta} = u,\\
    &v_0\in \mathbb{R}^+,\\
    &\theta \in \;]\!-\!\pi,\pi],\\
    &u \in \left[-\frac{v_0}{\rho},\frac{v_0}{\rho}\right],\\
    &\rho \leq r_c,
\end{align}
where $\rho$ is the minimal turning radius of the Dubins vehicle

\subsubsection*{Terminal conditions}

The vehicle has to go from its initial point $(x_0,y_0)$ to a point $(x_g,y_g)$ located on the perimeter of $\mathcal{C}$, then return to a point $(x_f,y_f)$ located on the boundary of $\mathcal{X}$.

\subsubsection*{Cost function}

The cost function is (almost same notation as \cite{Manyam2017})
\begin{align}
    \underset{u(t)}{\min}\int_0^T 1dt
\end{align}
where $T$ is the time it takes to go from $(x_0,y_0)$ to $(x_f,y_f)$ while transiting through $(x_g,y_g)$.

Although the objective is to find the fastest path, since the vehicle travels at a constant speed and is assumed to be in a homogeneous environment (friction and drag are constant, and no external perturbations), finding the fastest path is equivalent to finding the shortest path.

\section{Figuring out how to do it}

As a starting hypothesis, we find the point on the perimeter of $\mathcal{X}$ that is closest to the starting point $(x_0,y_0)$, then find the Dubins path to that point. Since $\mathcal{X}$ was defined as a circle, the closest point to the starting position would be given by
\begin{align}
    d = \sqrt{(x_x-x_0)^2 + (y_x-y_0)^2} - r_x.
\end{align}
This point might not be the point that gives the shortest path from the starting point depending on the starting angle $\theta_0$, so we might change this later to look at multiple different points on the perimeter of $\mathcal{X}$ to see which one gives the shortest Dubins path (although this might be inefficient computing wise). Also, we might want to check if one of those paths will intersect with $\mathcal{C}$.

We also need to find at what angle we will arrive in $\mathcal{X}$. That angle will be the angle that helps get the shortest Dubins path. Need to look into that more...

Then, we need to check if the Dubins path intersects with $\mathcal{C}$. To do this, for every point $(x,y)$ of the (discretized) Dubins path, we have to check if the following condition is true
\begin{align}
    \sqrt{(x_c-x)^2 + (y_c-y)^2} \leq r_c.
\end{align}
If it is true for one point $(x,y)$, then we simply apply the already computed Dubins path to the vehicle. If it's not true, we need to use the method from \cite{Jha20} to get a new path that will intersect with $\mathcal{C}$ in one point (no need to intersect more than that).
